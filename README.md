# Foodgram - Продуктовый помощник

## Описание проекта

Foodgram — это веб-приложение, которое позволяет пользователям делиться рецептами, подписываться на других авторов, добавлять рецепты в избранное и формировать список покупок. Проект состоит из двух частей: фронтенда (React) и бэкенда (Django REST Framework), которые работают вместе.

### Основные возможности:
- Регистрация и авторизация пользователей
- Просмотр, создание, редактирование и удаление рецептов
- Поиск рецептов по тегам и ингредиентам
- Подписка на авторов
- Добавление рецептов в избранное
- Формирование списка покупок и его скачивание
- Загрузка и изменение аватара пользователя

## Стек технологий

### Бэкенд:
- **Python 3.12**
- **Django 4.2**
- **Django REST Framework 3.14**
- **Djoser** - аутентификация и управление пользователями
- **django-filter** - фильтрация и поиск
- **Pillow** - обработка изображений
- **Gunicorn** - WSGI-сервер для продакшена
- **PostgreSQL** - база данных (в продакшене)

### Фронтенд:
- **React**
- **Redux Toolkit**
- **React Router**
- **Vite**

### Инфраструктура:
- **Docker** и **Docker Compose**
- **Nginx** - веб-сервер и прокси
- **GitHub Actions** - CI/CD (опционально)

## Как развернуть контейнеры на сервере

### Предварительные требования:
- Установленный Docker и Docker Compose
- Сервер с доступом в интернет
- Домен (опционально, для продакшена)

### чтобы запустить проект:
1 сделать миграции manage.py makemigrations\python manage.py migrate
2 выполнить команду для заполнения бд. python manage.py shell < fill_database.py
3 запустить проект python manage.py runserver
